# Maru Lipi Backend

Serverless literature API using Python, FastAPI, AWS Lambda, API Gateway, and DynamoDB.

## Initial setup

This repository will contain the backend API for Maru Lipi. The first milestone is a read API for published poems, stories, and essays, plus protected admin endpoints to create, update, and delete literature.

## Planned deployment

- AWS Lambda + API Gateway
- DynamoDB (pay-per-request)
- AWS SAM deployment template

## Security

Never commit AWS access keys, passwords, or the admin token. Check current AWS pricing and Free Tier eligibility before deploying resources.
